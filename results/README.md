# FortBO benchmark results

Raw CSV and JSON records will be added with each acquisition and surrogate
implementation. Every row records source/toolchain/device provenance and keeps
CPU, transfer-inclusive GPU, resident GPU, and typed refusal states separate.

The release evidence generated by `scripts/run_benchmark.py` is:

- `bench_suite.csv`: one raw row per function, acquisition, surrogate, and
  device lane;
- `../fixtures/bench_suite.json`: complete metrics, worker replay, and oracle
  records;
- `bench_suite.svg`: a dependency-free plot of the derivative-gate errors.
